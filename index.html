16-Bit Q10 Fixed-Point ALU

Floating-point hardware in smartwatches consumes excessive microwatts. By scaling sensor values by 1024 (2^10), standard integer ALU instructions execute high-precision accelerometer and optical filtering in single clock cycles.

Magnitude Squared vs. SQRT Stalls

Computing Euclidean magnitude |A| = sqrt(x^2 + y^2 + z^2) requires a hardware square root taking 14-34 cycles. Cortex-M computes |A|^2 via MUL + 2x MLA and compares directly to T^2 = 2,423,296 in 3 single cycles!

Power-of-2 Stride Cache Conflict

The 4 ring buffers (ax, ay, az, ppg) are aligned on 0x0400 (1,024B) boundaries. In 1-Way and 2-Way caches, simultaneous sample reads map to the exact same cache set (Set 0), causing 50% hit thrashing. A 4-Way cache keeps all 4 lines co-resident!

COA Architecture Guide Cortex-M

1. Live Web Bluetooth GATT Bridge

Connects to your physical smartwatch using the Web Bluetooth API (navigator.bluetooth.requestDevice). It queries standard services: Heart Rate (0x180D / 0x2A37), Running Speed & Cadence (0x1814 / 0x2A53), and Battery (0x180F / 0x2A19). If your smartwatch conceals standard UUIDs behind proprietary vendors, it automatically activates the Hardware Telemetry Stream fallback with DeviceMotion shake support!

2. 16-Bit Q10 Fixed-Point ALU Architecture

Smartwatches operate in the microwatt power envelope. Instead of bulky floating-point hardware or slow software emulations, accelerometer and optical PPG readings are scaled by 1024 (Q10 format). Step detection computes |A|^2 = ax^2 + ay^2 + az^2 and compares against T^2 = 2,423,296 using single-cycle MUL and MLA, eliminating hardware square-root stalls!

3. Power-of-2 Stride Cache Conflict & 4-Way LRU

The 4 ring buffers (ax, ay, az, ppg) reside at 0x2000_0000, 0x2000_0400, 0x2000_0800, and 0x2000_0C00. Because 1,024 bytes is a power-of-2 multiple of cache block and set sizes, simultaneous reads to sample n all map to Set #0! Direct-mapped (1-way) and 2-way caches suffer pathological conflict thrashing (~50% hit rate). A 4-Way Set Associative Cache holds all 4 lines concurrently, achieving an optimal 91.66% hit rate!

4. 5-Stage Pipeline Hazards & Forwarding

With EX/MEM -> EX Data Forwarding, ALU-to-ALU RAW hazards incur 0 stall cycles. Load-Use hazards (LDRSH -> MUL) require only a 1-cycle bubble. Combined with a Dynamic 2-Bit Saturating Counter BHT for loop branches, the effective CPI improves from 2.26 down to 1.32!

⌚ Smartwatch Bluetooth Troubleshooting

1. Watch not showing in browser list?

Smartwatches (Noise, boAt, Fire-Boltt, Amazfit) only broadcast Bluetooth advertising when they are disconnected from your phone! Temporarily turn off Bluetooth on your smartphone so your watch enters pairing mode.

2. Already paired in Windows Bluetooth Settings?

If you already connected your watch to Windows via Settings -> Bluetooth & devices, click "Link Paired Watch" to immediately bind your live hardware telemetry stream into the simulation!

3. Garmin / Apple Watch broadcast:

- Garmin: Go to Settings -> Wrist Heart Rate -> Broadcast Heart Rate -> Start.
- Apple Watch: Open a BLE heart rate broadcaster app (e.g. HeartCast) from the App Store.
